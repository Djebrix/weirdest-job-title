One job title, 60 characters or fewer — the weirdest I could think of.

**The title:** Senior Apologizer to the Third-Floor Printer

`main.py` (stdlib only, no network, deterministic) writes the title to
`entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`).

Run it:

```sh
python3 main.py
```
